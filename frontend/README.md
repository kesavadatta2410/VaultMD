# VaultMD (frontend)

Static demo UI for VaultMD — a privacy-first health record platform. This
Space serves only the frontend; the backend (Spring Boot) and ai-service
(FastAPI RAG) run separately on Render's free tier. See the main repo for
the full project: https://github.com/kesavadatta2410/VaultMD
